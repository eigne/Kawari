# Troubleshooting

## "World data could not be obtained"/"There are no service accounts"

This happens when the Lobby server could not connect to the World server, check if it's running or if you modified something in your [config](configuration.md).

## Client says a version update is required

Check that the client version matches what Kawari expects (see the README), and that Kawari itself is configured to the correct directory. Additionally, if you applied patches while Kawari was running you need to restart Kawari again.
